Check a digital signature

This page checks, in your own browser, that a record was signed with the key it names and has not been changed since. It sends nothing anywhere and does not need the application the record came from: the file you open holds the signed text, the signature and the public key. You can save this page and use it offline.

What this proves, and what it does not

        
It proves the text is exactly what the key holder signed, and that nobody changed a character since. It does not say who holds the key: compare the key's
            fingerprint shown above with the one the issuer gave you separately (printed on the document or told to you in person). If they are the same, the record is the issuer's and is unchanged.

        
Check it without this page
            
from base64 import b64decode
import json
from cryptography.hazmat.primitives import hashes, serialization
from cryptography.hazmat.primitives.asymmetric import ec
from cryptography.hazmat.primitives.asymmetric.utils import encode_dss_signature

b = json.load(open("evidence.json"))
key = serialization.load_der_public_key(b64decode(b["publicKey"]))
sig = b64decode(b["signature"])
r, s = int.from_bytes(sig[:32], "big"), int.from_bytes(sig[32:], "big")
key.verify(encode_dss_signature(r, s), b["signedText"].encode("utf-8"), ec.ECDSA(hashes.SHA256()))
print("valid")   # raises InvalidSignature if anything differs
